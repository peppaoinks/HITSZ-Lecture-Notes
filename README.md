## 编译与更新

使用 XeLaTeX 连续编译两次，让目录与页码保持一致。例如在 `数字逻辑设计/` 中运行：

```sh
xelatex -interaction=nonstopmode -halt-on-error -output-directory=. 源文件/数字逻辑设计讲义.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=. 源文件/数字逻辑设计讲义.tex
```

源文件集中定义字体、主题色和信息框，主要使用宋体、Times New Roman、TeX Gyre Termes Math；代码使用等宽字体。提供兼容字体回退，不同字体环境可能改变分页。仓库 PDF 使用指定的本机字体导出。图示全部包含在单文件源中，无需外部图片。

新增内容应合并到最新版相应章节，保留已经接受的内容与纠正，随后同步更新 PDF，并检查公式、表格、信息框、图形连线、目录与分页。实验代码的教学检查不等同于 Vivado 综合、布局布线或上板验收；实验年份、开发板与接口以正文说明为准。
