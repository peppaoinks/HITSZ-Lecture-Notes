# 机器学习讲义：第一至十五章配套实验

当前正式讲义包含第1—15章，早期各批记录保留如下；最新依赖与入口见文末第13—15章说明。第1—3章仅用Python标准库，第4、6章使用NumPy，第5章增加pandas与Matplotlib。全部数据为教学构造，不读取个人资料，不连接外部服务，不下载数据。第四章性能对照另用固定种子的伪随机数据。

## 环境与第一次运行

在普通终端检查 `python3 --version`。Windows 可用 `py -3 --version`。应确认使用 Python 3；第1—3章不需要第三方库，第4章需要NumPy，所有实验均无需付费接口。第二章讲解解释器、编辑器、终端和虚拟环境。

macOS 中可以执行：

```sh
cd "/Users/mac/Desktop/机器学习 ML/配套实验"
python3 ch01_regression.py
python3 ch01_classification.py
python3 ch02_basics.py
python3 ch02_metrics.py
python3 ch02_solutions.py
```

Windows 中切换到本目录，将 `python3` 替换为 `py -3`。不应将这些终端命令写到 Python 文件或输入到 `>>>` 提示符之后。所有程序无交互输入，直接运行并退出。

可选虚拟环境：在本项目目录创建 `python3 -m venv .venv`，然后按讲义中的系统说明激活。第1—3章创建环境后不需要安装包；第4章在该环境执行 `python3 -m pip install numpy`。本批实际核对环境为Python 3.12.14、NumPy 2.3.5。

近邻、缩放和MAE接口共用实数输入检查，先转成独立float64数组，避免整数做差回绕；拒绝布尔、复数、字符串和一般对象数组。输入必须有限，缩放、距离、平均和MAE的中间计算溢出时会抛出`FloatingPointError`，应检查数据尺度。不能把关闭警告或全无穷距离视为有效计算。

线性计算采用float64，相对和绝对容差均为1e-12；先检查形状与数值，再各计时3次并报告中位数。最大数值差与耗时依赖机器和数值库，不规定固定加速倍数。随机生成器种子2026仅用于性能输入，实际近邻数据和划分固定。

`ch04_results/summary.json`记录版本、种子、训练参数、指标、数值差与计时；`arrays.npz`保存命名数组和形状。用 `np.load(..., allow_pickle=False)`读取普通数值数组，需按讲义保持路径起点一致。

修改任务：把标签变成列数组应被接口拒绝；移除标准化须重做验证选择；第三列各集合一起由1改5，标准化值仍为0且预测不变；批大小1、2、10的结果应与完整批量一致；改float32时另外记录容差与类型，不能混用计时条件。
