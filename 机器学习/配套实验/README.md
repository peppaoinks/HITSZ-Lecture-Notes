# 机器学习讲义：第一至四章配套实验

当前讲义包含第1—4章。第1—3章仅用Python标准库，第4章增加NumPy。全部数据为教学构造，不读取个人资料，不连接外部服务，不下载数据。第四章性能对照另用固定种子的伪随机数据。

## 环境与第一次运行

在普通终端检查 `python3 --version`。Windows 可用 `py -3 --version`。应确认使用 Python 3；第1—3章不需要第三方库，第4章需要NumPy，所有实验均无需付费接口。第二章讲解解释器、编辑器、终端和虚拟环境。

macOS 中可以执行：

```sh
cd "/Users/mac/Desktop/机器学习 ML/配套实验"
python3 ch01_regression.py
python3 ch01_classification.py
python3 ch02_basics.py
python3 ch02_metrics.py
python3 ch02_solutions.py
```

Windows 中切换到本目录，将 `python3` 替换为 `py -3`。不应将这些终端命令写到 Python 文件或输入到 `>>>` 提示符之后。所有程序无交互输入，直接运行并退出。

可选虚拟环境：在本项目目录创建 `python3 -m venv .venv`，然后按讲义中的系统说明激活。第1—3章创建环境后不需要安装包；第4章在该环境执行 `python3 -m pip install numpy`。本批实际核对环境为Python 3.12.14、NumPy 2.3.5。

## 主要预期值

- 实验1.1：验证基线MAE=3.05；k=1、3、5的验证MAE依次为0.1、0.241666…、0.54；选k=1；测试基线MAE=2.95，选定方案MAE=0.7。四个预测为5.6、10.2、11.7、16.1。
- 实验1.2：阈值0.5下计数(2,2,3,1)，阈值0.7下计数(1,1,4,2)，顺序为TP/FP/TN/FN。准确率均为0.625，精确率均为0.5，召回率分别为2/3和1/3。
- 实验2.1：有效值 `[82, 91, 76, 88, 0]`；拒绝下标2、4、7、8；数量5、均值67.4、最小0、最大91、及格比例0.8。`describe([])`返回`None`。
- 实验2.2：A的MAE=1、MSE=1.5、RMSE≈1.224744871；B的MAE=1、MSE=4、RMSE=2。最坏误差下标均为3。非法输入应被主动拒绝。
- 答案脚本：最后打印 `all checks passed`。

离散计数、下标和列表必须一致；浮点内部结果允许约1e-9的绝对差异。保留六位小数只是显示约定，不代表数据有六位小数测量精度。

## 修改任务与核对方式

每项修改从原版开始，先手算，再运行，记录哪些条件改变。

### 实验1.1

1. 训练第二条费用由5.6改为9.6，手算验证输入0.8与测试输入1.2的近邻结果，再重新执行整个候选选择流程。
2. 对重量10.0单独预测，观察k=1的范围外结果。不提供真实标签时，不可将该输入并入原测试MAE。
3. 直接尝试k=0或13，应触发`ValueError`。

修改后的数据是新的实验条件，不能继续声称原先固定测试结论适用。不能根据测试分数反复选k。

### 实验1.2

1. 下标4的分数由0.4改为0.6。阈值0.5下应得到(3,2,3,0)、准确率0.75、精确率0.6、召回率1；阈值0.7保持原结果。
2. 计算`FP + 5 * FN`，原版两个阈值的成本分别7与11；修改后分别2与11。
3. 阈值改成1.1时，精确率为`None`。先判断是否为`None`，再选择显示字符串；固定小数格式不能直接格式化`None`。示例不是用于选择真实业务阈值的独立测试。

### 实验2.1

1. 将“105”改成“100”：数量6、均值437/6、及格比例5/6、最大100。
2. 单独将“absent”改成“59”：数量6、均值66、及格比例4/6。
3. 全无效输入返回`None`，调用者应先判断，再决定打印“无有效数据”，不调用`None.items()`。
4. 将清理逻辑整理成函数；参考`ch02_solutions.py`的习题2.15。原输入应保持不变，拒绝记录不应丢失。

### 实验2.2

1. B最后一项改为14：MAE=0.5、MSE=1、RMSE=1。
2. 给两个方案新增真实值20、A预测21、B预测24：从原版开始，A的MAE=1、MSE=1.4；B的MAE=1.6、MSE=6.4。RMSE为各自MSE的平方根。
3. 删除某预测最后一项，应拒绝长度不同，不能让`zip`悄悄截短。
4. 列出所有并列最大误差下标，说明是精确并列还是容差内近似并列。

## 实现边界

近邻实验只有一维输入和小数据，采用完整排序；分类实验输入固定为0/1标签与有限分数；统计实验只接受ASCII非负整数文本；指标实验要求有限数值且等长非空。脚本不是任意输入的生产系统。第3、4章已补充异常处理、文件组织、对象与数组类型、有限值和形状验证。

主讲义和源文件分别保存在上一级的`机器学习讲义.pdf`与`源文件/机器学习讲义.tex`。后续实验继续按章节编号加入此目录。


## 第三章：程序组织与调试

在配套实验目录运行：

```sh
python3 ch03_objects.py
python3 ch03_project/main.py
python3 ch03_project/test_project.py
python3 ch03_solutions.py
```

- `ch03_objects.py`（实验3.1）：引用、浅复制、深复制、独立默认列表、循环变量绑定与JSON往返；临时文件自动清理。最终输出 `all checks passed`。
- `ch03_project/main.py`（实验3.2）：读取 `data/parcels.csv`，严格核对表头、字段数量、唯一标识、划分名和有限非负数值；每组4条；按验证MAE选择均值或单近邻，不合并验证集重训。
- `ch03_project/test_project.py`：5项标准库测试，核对手算、失败路径、模型状态、复制语义、CSV格式和固定数据的预测。
- `ch03_solutions.py`：核对习题中的非负有限数值解析、引用、绑定与文本往返。

实验3.2验证MAE：均值1.8，单近邻0.4；选单近邻；最终预测 `[6.0, 10.0, 10.0, 12.0]`，测试MAE=0.85，预先声明的均值基线MAE=2.05。浮点误差允许约1e-12。

输出保存在 `ch03_project/results/summary.json` 和 `predictions.csv`。JSON记录Python版本、输入文件SHA-256摘要、划分数量、候选顺序、选择规则、重训约定和指标；CSV记录逐条标识、标签、预测与绝对误差。摘要用于辨认文件字节，不证明数据质量。

入口以真实脚本目录定位数据和输出，可从其他目录用其绝对路径运行。普通导入 `models`、`metrics` 或 `main` 不会启动实验或写结果。重复成功运行会覆盖固定输出；失败后可能留有旧输出，不能将旧文件当成本轮成功。

修改任务每次使用原始CSV的副本并单独恢复。把数值改为nan、重复标识、未知集合、缺字段和多字段均应被拒绝。只把第一条训练费用6改为10：两候选验证MAE分别1.8、1.2，仍选单近邻，最终测试MAE变为1.45；需重新生成全部相应报告。对重量100单独预测为12，说明近邻的外推限制。

## 第四章：NumPy与向量化

先在当前环境确认可以 `import numpy`，再运行：

```sh
python3 ch04_arrays.py
python3 ch04_numeric.py
python3 ch04_solutions.py
```

- `ch04_arrays.py`（实验4.1）：形状、轴归约、中心化、视图与高级索引副本、错误广播、稳定指数归一化、相同种子重新创建生成器的核对。
- `ch04_numeric.py`（实验4.2）：3特征固定数据，训练、验证、测试各4条；仅从训练集估计均值与尺度；比较k=1、3的循环和广播实现；同时对12000×12数值数据比较循环线性计算与矩阵乘法。
- `ch04_solutions.py`：手算、静默广播错误、等形验证、常数列、分块预测及非法k检查。

实验4.1关键值：形状 `(2, 3)`，轴0求和 `[5, 7, 9]`，轴1求和 `[6, 15]`；列切片 `(2,)` 与 `(2, 1)`；视图共享真、高级索引副本共享假；错误残差 `(3, 3)`，MSE=4/3，修正后0；稳定归一化各行和为1。

实验4.2训练均值 `[[1.5, 15, 1]]`，尺度 `[[sqrt(1.25), 5, 1]]`，第三列标准差0按规则用1替代。验证k=1的MAE为0.4，k=3为22/15≈1.4666667，选择k=1。测试预测 `[4, 8, 8, 10]`，测试MAE=0.85，训练均值基线MAE=2.05。循环和向量化近邻采用同一稳定同分规则，按绝对容差1e-12核对。

线性计算采用float64，相对和绝对容差均为1e-12；先检查形状与数值，再各计时3次并报告中位数。最大数值差与耗时依赖机器和数值库，不规定固定加速倍数。随机生成器种子2026仅用于性能输入，实际近邻数据和划分固定。

`ch04_results/summary.json`记录版本、种子、训练参数、指标、数值差与计时；`arrays.npz`保存命名数组和形状。用 `np.load(..., allow_pickle=False)`读取普通数值数组，需按讲义保持路径起点一致。

修改任务：把标签变成列数组应被接口拒绝；移除标准化须重做验证选择；第三列各集合一起由1改5，标准化值仍为0且预测不变；批大小1、2、10的结果应与完整批量一致；改float32时另外记录容差与类型，不能混用计时条件。
