# 机器学习讲义：第一、二章配套实验

当前讲义只包含第一章《人工智能与机器学习全景》和第二章《Python语言基础》。所有数据均为固定教学数据，不读取个人资料，不连接外部服务，不下载数据。全部程序仅使用 Python 3 标准库。

## 环境与第一次运行

在普通终端检查 `python3 --version`。Windows 可用 `py -3 --version`。应确认使用 Python 3；示例不需要 NumPy、pandas 或付费接口。第二章讲解解释器、编辑器、终端和虚拟环境。

在讲义目录下，macOS 或 Linux 中可以执行：

```sh
cd 配套实验
python3 ch01_regression.py
python3 ch01_classification.py
python3 ch02_basics.py
python3 ch02_metrics.py
python3 ch02_solutions.py
```

Windows 中切换到本目录，将 `python3` 替换为 `py -3`。不应将这些终端命令写到 Python 文件或输入到 `>>>` 提示符之后。所有程序无交互输入，直接运行并退出。

可选虚拟环境：在本项目目录创建 `python3 -m venv .venv`，然后按讲义中的系统说明激活。由于没有第三方依赖，创建环境后不需要安装包。

## 主要预期值

- 实验1.1：验证基线MAE=3.05；k=1、3、5的验证MAE依次为0.1、0.241666…、0.54；选k=1；测试基线MAE=2.95，选定方案MAE=0.7。四个预测为5.6、10.2、11.7、16.1。
- 实验1.2：阈值0.5下计数(2,2,3,1)，阈值0.7下计数(1,1,4,2)，顺序为TP/FP/TN/FN。准确率均为0.625，精确率均为0.5，召回率分别为2/3和1/3。
- 实验2.1：有效值 `[82, 91, 76, 88, 0]`；拒绝下标2、4、7、8；数量5、均值67.4、最小0、最大91、及格比例0.8。`describe([])`返回`None`。
- 实验2.2：A的MAE=1、MSE=1.5、RMSE≈1.224744871；B的MAE=1、MSE=4、RMSE=2。最坏误差下标均为3。非法输入应被主动拒绝。
- 答案脚本：最后打印 `all checks passed`。

离散计数、下标和列表必须一致；浮点内部结果允许约1e-9的绝对差异。保留六位小数只是显示约定，不代表数据有六位小数测量精度。

## 修改任务与核对方式

每项修改从原版开始，先手算，再运行，记录哪些条件改变。

### 实验1.1

1. 训练第二条费用由5.6改为9.6，手算验证输入0.8与测试输入1.2的近邻结果，再重新执行整个候选选择流程。
2. 对重量10.0单独预测，观察k=1的范围外结果。不提供真实标签时，不可将该输入并入原测试MAE。
3. 直接尝试k=0或13，应触发`ValueError`。

修改后的数据是新的实验条件，不能继续声称原先固定测试结论适用。不能根据测试分数反复选k。

### 实验1.2

1. 下标4的分数由0.4改为0.6。阈值0.5下应得到(3,2,3,0)、准确率0.75、精确率0.6、召回率1；阈值0.7保持原结果。
2. 计算`FP + 5 * FN`，原版两个阈值的成本分别7与11；修改后分别2与11。
3. 阈值改成1.1时，精确率为`None`。先判断是否为`None`，再选择显示字符串；固定小数格式不能直接格式化`None`。示例不是用于选择真实业务阈值的独立测试。

### 实验2.1

1. 将“105”改成“100”：数量6、均值437/6、及格比例5/6、最大100。
2. 单独将“absent”改成“59”：数量6、均值66、及格比例4/6。
3. 全无效输入返回`None`，调用者应先判断，再决定打印“无有效数据”，不调用`None.items()`。
4. 将清理逻辑整理成函数；参考`ch02_solutions.py`的习题2.15。原输入应保持不变，拒绝记录不应丢失。

### 实验2.2

1. B最后一项改为14：MAE=0.5、MSE=1、RMSE=1。
2. 给两个方案新增真实值20、A预测21、B预测24：从原版开始，A的MAE=1、MSE=1.4；B的MAE=1.6、MSE=6.4。RMSE为各自MSE的平方根。
3. 删除某预测最后一项，应拒绝长度不同，不能让`zip`悄悄截短。
4. 列出所有并列最大误差下标，说明是精确并列还是容差内近似并列。

## 实现边界

近邻实验只有一维输入和小数据，采用完整排序；分类实验输入固定为0/1标签与有限分数；统计实验只接受ASCII非负整数文本；指标实验要求有限数值且等长非空。脚本不是任意输入的生产系统。更完整的异常处理、文件组织、类型与数值验证将在后续章节展开。

主讲义和源文件分别保存在上一级的`机器学习讲义.pdf`与`源文件/机器学习讲义.tex`。后续实验继续按章节编号加入此目录。
