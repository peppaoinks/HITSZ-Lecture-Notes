# 机器学习讲义大纲

用户已于2026年10月8日授权按本大纲开始编写第一、二章，并新建专门的编写对话。后续按完整章节分批编写，持续汇入同一部讲义。

## 编写定位与规模

- 面向计算机科学与技术专业大二学生；Python 近零基础；高等数学、线性代数学过但需要复习，概率统计正在学习。
- 目标：系统理解人工智能，形成能够独立完成实验与项目、继续选择实习方向的基础。
- 知识扫盲：贯穿全书解释基础概念、常用术语、工具用途和知识之间的联系，补齐必要先修背景，不默认读者熟悉行业常识；同时保持推导与实践深度。
- 深度：直觉与推导并重。重要算法包括动机、明确的模型假设、符号与维度、关键推导、中间步骤、手算例题、实现、评价与适用边界。
- 规模：8篇、44章及附录，预计约600–800页。按与大学物理讲义一致的字号、行距和页边距估算，实际页数随推导、图示和实验内容确定。
- 核心算法章节通常约15–25页；工具与概览章节通常约10–18页；综合项目章节通常约20–30页。复杂章节可以更长。
- 学习路线以第1–37章为主，第38–40章提供后续方向拓展，第41–44章完成项目与工程实践。
- 主讲义专注知识。建议时长、阅读顺序、免费线上课程及课程对应章节，放在独立的《学习建议与线上课程》PDF中；不设置周记录、打卡表或自动跟踪。

## 第一篇：编程与数学准备（第1–8章）

### 第1章 人工智能与机器学习全景
1. 人工智能、机器学习、深度学习与大语言模型的关系。
2. 监督、无监督、自监督与强化学习；回归、分类、生成、检索与决策。
3. 样本、特征、标签、模型、参数、超参数、损失与指标。
4. 从实际需求定义预测目标、数据来源和评价方案。
5. 训练、验证、测试与泛化；一个从数据到评价的完整小案例。

### 第2章 Python 语言基础
1. 解释器、编辑器、终端、脚本、虚拟环境与依赖。
2. 数值、字符串、布尔值、变量、运算与浮点误差。
3. 条件判断、循环、列表、元组、字典、集合与切片。
4. 函数、参数、返回值、作用域与列表推导式。
5. 逐行执行分析、基础程序练习及详细答案。

### 第3章 Python 程序组织与调试
1. 模块、导入、文件路径、文件读写与异常处理。
2. 对象、类、实例、方法：理解后续机器学习库所需的最小面向对象基础。
3. 可变对象、引用、复制与副作用。
4. 阅读报错、检查中间结果、断言和最小测试。
5. 把数据读取、训练、预测、评价组织成可复现的小程序。

### 第4章 NumPy 与向量化计算
1. 数组、类型、轴、形状、索引、切片和视图。
2. 广播规则、逐元素运算、矩阵乘法与维度核对。
3. 归约操作、随机数、固定种子与数值稳定性。
4. 从逐样本循环到向量化的逐步改写。
5. 常见广播错误与一个完整的数值实验。

### 第5章 pandas、数据探索与可视化
1. CSV、DataFrame、字段类型、缺失值和重复数据。
2. 筛选、分组、聚合、合并与数据检查。
3. 描述统计、分布、异常值、相关性与标签分布。
4. Matplotlib 的散点图、直方图、曲线与多图比较。
5. 形成一份有明确问题与结论的数据探索报告。

### 第6章 线性代数复习
1. 向量、内积、范数、距离与余弦相似度。
2. 矩阵、线性变换、秩、列空间与正交投影。
3. 最小二乘的几何意义、线性方程和数值求解。
4. 特征值、特征向量、正定性、奇异值分解与条件数。
5. 矩阵微分的必要规则与后续公式的维度检查。

### 第7章 微积分复习与优化准备
1. 导数、偏导、梯度、方向导数与局部近似。
2. 链式法则、多路径导数与计算图。
3. Hessian、凸性、驻点与极值的区别。
4. 梯度下降的几何解释、步长与二次函数收敛。
5. 有限差分、梯度检查与数值误差。

### 第8章 概率统计与信息论准备
1. 随机变量、分布、密度、条件概率、独立性与贝叶斯公式。
2. 期望、方差、协方差、常见分布与抽样波动。
3. 估计、似然、最大似然与最大后验。
4. 熵、交叉熵、KL散度及其与损失函数的关系。
5. 置信区间、重采样与评价结果的不确定性；与正在学习的概率统计课程衔接。

## 第二篇：监督学习的共同基础（第9–14章）

### 第9章 学习问题的数学表达

2. 经验风险、期望风险、正则化与优化问题。

### 第10章 数据划分与特征工程
1. 随机、分层、时间和分组划分。
2. 填补、标准化、类别编码、文本特征与异常值处理。

### 第11章 线性回归、岭回归与Lasso
1. 一元、多元与多项式回归；完整手算拟合。

3. 混淆矩阵、准确率、精确率、召回率、F1、ROC与PR。
4. 指标与任务成本、概率指标、基线和置信区间。
5. 错误分析、消融实验、多次试验与测试集使用纪律。

## 每章固定展开方式

1. 学习目标、先修知识与本章在全书中的位置。
2. 从具体问题建立直觉，说明为什么需要该方法。
3. 定义、符号、维度、假设和适用条件。
4. 分小节逐步推导；解释关键变形依据。
5. 多个手算例题：基础计算、实际解释与边界情况。
6. 算法步骤、伪代码、实现与复杂度。
7. Python实验：依赖、输入、关键代码、预期结果、修改任务和结果解释。
8. 与相关方法比较、常见误区、失效情形与选择依据。
9. 本章知识联系与自检。
10. 分层练习：概念、计算、推导、编程或实验；参考答案提供必要步骤。

不是所有章节都强行使用同样数量的例题。核心算法章节原则上安排3–5个手算或推导例题、1–2个完整实验和约8–12道分层习题；编程和项目章节调整为相应数量的代码分析、调试任务与项目检查点。
