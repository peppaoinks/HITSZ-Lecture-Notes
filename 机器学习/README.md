# 机器学习讲义

一部面向初学者、适合自学的中文机器学习讲义。讲义同时承担知识扫盲功能：解释基础概念、常用术语、工具用途和知识之间的联系，并结合数学推导、手算例题、Python 实验与分层习题展开。

**本书仍在编写中，我后续会持续补充完整章节、例题、实验与习题答案，并同步更新累计 PDF 和 LaTeX 源文件。**

## 当前内容

当前正文版本为 2026-10-18，已完成第1—15章：

1. 人工智能与机器学习全景。
2. Python 语言基础。
3. Python 程序组织与调试。
4. NumPy 与向量化计算。
5. pandas、数据探索与可视化。
6. 线性代数复习。
7. 微积分复习与优化准备。
8. 概率统计与信息论准备。
9. 学习问题的数学表达。
10. 数据划分与特征工程。
11. 线性回归、岭回归与Lasso。
12. 优化算法与训练诊断。
13. 逻辑回归与多分类。
14. 泛化、模型选择与可靠评价。
15. k近邻与距离学习。

十五章共含98个编号例题、31个主实验和200道附参考答案的分层习题，另有学习曲线补充与答案核对入口。本批第13—15章共46页（15、15、16页），新增17个例题、6个主实验、1个补充实验、3个答案入口与38道习题；独立版保留正文页码229—274。累计版281页，前十二章228页正文与原版逐页文本一致。完整规划仍为8篇44章，未完成章节不列入正文目录。

## 编译

在本目录使用 XeLaTeX 连续编译两次，以更新目录和页码：

```sh
xelatex -interaction=nonstopmode -halt-on-error -output-directory=. 源文件/机器学习讲义.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=. 源文件/机器学习讲义.tex
```

源文件为单文件文档，图示在文内生成，无需外部图片。版式沿用本仓库大学物理讲义，采用宋体、Times New Roman、数学字体及等宽代码字体；源码提供字体回退，不同环境的分页可能略有差异。
